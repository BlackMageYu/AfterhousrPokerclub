# 2026-09-08 v1.0.3 动画、牌面与 UTF-8 修复

适用版本：v1.0.3
目标：调整公共牌与下注筹码动画，修复旋转牌面的白色外框／锯齿问题，以及结算面板中的中文乱码。

## 实现内容

### 公共牌与筹码动画

- 翻牌、转牌、河牌不再先显示牌背或执行横向翻转。公共牌从发牌位置以正面朝上直接平滑移动到公共牌区域。
- 下注时保留筹码从 1 层增加到 3 层的视觉反馈，但每一层直接出现在相应下注位；不再从玩家头像或手牌位置飞入桌面。
- 动画位移采用 `CubicEase` 缓入缓出，避免公共牌移动出现突兀的线性停顿。

实现入口：[TableView.cs](../native/TableView.cs)。

### 牌面边缘

- 52 张牌面均保留内部的米白纸色与深色圆角边框。
- 将黑色边框外、且与图像边缘连通的纸色像素清除为透明；因此牌面在 WPF 中旋转时不再露出白色矩形底。
- 牌面控件启用高质量位图缩放、设备像素对齐与布局取整，减轻斜放卡牌边缘的锯齿。
- 牌背没有被重新生成或替换。

牌面生成入口：[build-flat-q-card-faces.ps1](../scripts/build-flat-q-card-faces.ps1)，读取入口：[MainWindow.cs](../native/MainWindow.cs)。

### 结算乱码

“本场已结束”窗口中的原因字段来自 C# WPF 窗口发送给本地 Node 规则进程的 `end` 命令。此前进程标准输入使用运行时默认代码页，中文原因在到达规则进程前可能损坏；规则进程再正确返回这个已损坏的字符串，因此只在结算原因一行表现为乱码。

现改为在 [Core.cs](../native/Core.cs) 中向标准输入流写入 UTF-8 字节，再由 Node 按 UTF-8 读取。原本的标准输出／错误输出 UTF-8 设置保持不变。桌面 QA 将 `原生端到端验收` 作为结束原因往返，并断言返回文案完全相同。
