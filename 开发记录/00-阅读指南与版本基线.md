## 本次重建的核心结论

1. 客户端窗口、布局、按钮、扑克牌和复盘界面使用 C# / WPF 原生绘制。
2. 已移除运行入口对 Electron、浏览器窗口、HTML/CSS 界面和本地 HTTP 服务的依赖。
3. 规则与策略保留 JavaScript，由随包携带的 `runtime/rules.exe` 执行，经隐藏子进程的标准输入输出与原生窗口通信。
4. “原生客户端”描述的是界面和桌面交互技术，不代表所有业务代码已经改写为 C#、单进程运行或编译成单个机器码文件。
5. 基础规则、人物、统计、策略与报告以旧项目为移植来源；对文档与源码冲突的部分，按本次需求修正并补充回归验证。
