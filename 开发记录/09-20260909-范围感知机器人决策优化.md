# 2026-09-09 范围感知机器人决策优化

适用版本：v1.1。
目标：让本地与外接 AI 控制的机器人依据可见行动重建对手范围，减少“把所有未知手牌当随机牌”造成的不真实跟注、过牌与价值判断。

## 1. 信息边界

范围模型只读取当前机器人本来可见的数据：自己的底牌、公共牌、位置、下注历史、存活玩家筹码、已积累的 VPIP/PFR，以及已公开的亮牌／诈唬记忆。

它不会读取其他玩家真实底牌、牌堆、烧牌或未来公共牌。模拟中的对手底牌来自未知牌堆的候选组合；候选组合先按公开范围加权抽取，再发出剩余公共牌。

## 2. 本地范围与权益模型

实现入口：[bot.js](../src/bot.js)。

- `opponentRangeProfile` 根据每名对手的按钮相对位置、翻前 open/3bet/4bet、跟注次数、翻后主动下注／跟注次数及有足够样本时的 VPIP/PFR，生成一个公开范围下限与行动画像。
- `opponentRangeWeight` 对未知牌堆中的每个候选两张牌计算权重：翻前强度、高口袋对子、同花、连张会受范围画像影响；翻后主动行动更偏向成牌和听牌，但保留有限的诈唬尾部。
- `estimateEquity` 不再把对手直接随机发两张牌，而是为每个存活对手从其公共范围中抽样，随后才补齐未知公共牌并比较牌力。
- 抽样量分层：普通翻牌圈 160 次；一般转牌／河牌 300 次；转牌或河牌且满足底池至少 25BB、多人池或需投入至少 50% 当前底池时为 700 次。

700 次是复杂位的定向权益估计，不是完整 GTO 求解。它比全局 1,000 次更适合桌面客户端：把计算量集中在真正会影响大额筹码的决定上。

## 3. 公开形象与抓诈边界

已公开的诈唬不会让机器人把后续下注一律视为诈唬。其作用有两层：

1. 在对手翻后进攻范围中恢复有限的弱牌／诈唬尾部；
2. 仅在河牌、底池赔率不高于 38%、已有公开诈唬证据、且机器人仍有最低摊牌价值时，允许放宽一次边缘 bluff-catch。

这样一次亮牌会影响边缘决定，但不会推翻底池赔率、强牌范围或全下门槛。

## 4. 外接 AI 与本地保护

实现入口：[external-ai.js](../src/external-ai.js)。

- 每次外接请求额外发送 `opponentRanges`：这是从公开信息得到的范围摘要，而不是隐藏牌数据；系统提示也要求模型将其作为可错的先验。
- 普通局面维持关闭思考的短 JSON 请求；转牌／河牌大底池、多人池、高压跟注或强成牌，以及全下、边池、筹码承诺局面走审慎推理路径。
- 审慎推理未给出最终 JSON 时，只会重试一次关闭思考的 JSON 请求；不会把供应商的 `reasoning_content` 当作行动或写入日志。
- 河牌面对已投入对手、自己三条或更强、且不存在四同花／四连张危险时，若模型仍返回过牌，本地保护层会改成合法的价值下注，并在 `aiDecisions.guard.kind` 记录 `river-strong-value-check-override`。

## 5. 长期统计修复

实现入口：[career.js](../src/career.js)。

新桌中的角色初始统计为零；此前零值可能覆盖该角色已保存的 hands、VPIP、PFR 等历史值。现在以每个统计字段的较大值合并，因此同一 `characterId` 回到新桌时，范围模型可继续使用此前积累的公开统计。

- 新增范围回归：紧手加注者的范围下限高于松凶加注者；弱牌在紧范围中的权重低于强牌；复杂转牌启用 700 次抽样。
- 新增长期统计回归：新座位的零统计不会抹去同一角色保存的 VPIP/PFR。

## 7. 仍然存在的边界

- 范围是启发式加权模型，不是逐个 169 起手牌类别、逐条下注尺度训练出的均衡范围表。
- 权益抽样面对的是范围候选牌，不代表机器人知道对手真实底牌；抽样结果仍有统计波动。
- 外接模型可能不完全遵循范围摘要，因此关键价值漏注仍由本地合法性／价值保护层兜底。
- 本次验证覆盖逻辑、随机牌局和桌面启动；尚未在长时间真人实战与低性能硬件上测量每回合实际耗时。
