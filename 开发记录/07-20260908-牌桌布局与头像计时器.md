# 2026-09-08 牌桌参考图复刻与头像计时器

本次目标：以用户提供的 3840 × 1980 效果图为布局参考，重做实际游戏中的牌桌界面。后续补充要求是“头像周围一圈计时，头像里面显示倒计时”。

## 差异分析与改动

| 原界面问题 | 当前处理 |
| --- | --- |
| Viewbox 等比缩放、底部状态栏共同形成上下留边 | 牌桌采用 1500 × 773.4375 设计坐标，铺满客户端；常规保存状态不占屏幕高度 |
| 深绿色桌布、金色细边，地面与目标不同 | 以目标截图恢复空场背景，保留亮绿桌布、深色桌沿、宽木板人字拼地面 |
| 左侧及顶部玩家头像都放在名牌左边 | 左侧、顶部头像置于名牌右边；右侧与本人头像置于左边 |
| 常驻的岗位/BB 标签和文字行动提示使座位拥挤 | BB、位置、完整姓名与资金单位保留在鼠标提示中；行动显示为名牌底部色条 |
| 白底平铺手牌、细线背面 | 牌桌使用四色底牌、扇形重叠、灰色人字纹牌背；复盘保留白底牌与最佳五张金色高光 |
| 简单圆圈表示下注筹码 | 原生绘制带边缘纹理的筹码叠层、独立金额底板及六边形资金图标 |
| “D / BTN” 与岗位混在一起 | 原生白色圆形 D 按钮按真实庄家座位放置 |
| 操作区过高、按钮较小、单行文字 | 操作区按参考图置于右下；蓝色渐变大按钮，跟注/加注使用双行文字且金额加大 |
| 顶栏常驻五个按钮 | 左上保留菜单入口，补码、保存、音乐、设置、退出等原功能在菜单中 |
| 只在桌下用文字倒计时 | 当前行动头像叠加蓝色圆弧与中央数字，暂停及加时与规则时钟同步 |

保留 AfterHours 品牌、中文功能与真实人物/数值；不会把参考截图的外国用户名、SC 余额、固定手牌当成游戏状态。背景是 AI 重建素材，木纹、灯光与品牌字形存在细节差异，不能将其描述为截图逐像素复制。

## 头像计时圈实现

1. 当前玩家由 hand.actor 判定，只有该座位绘制计时覆盖层。
2. 玩家截止时间读取 actionDeadlineAt，开始时间读取 actionStartedAt。
3. 本地电脑读取 botTiming.dueAt、botTiming.startedAt；尚未取得实际截止时间时显示等待省略号，不虚构截止时间。
4. 中央数字为 ceil((deadline - now) / 1000)，最小为 0。
5. 蓝色 Path + ArcSegment 的角度为 360° × clamp((deadline - now) / (deadline - start))，底层保留暗蓝色圆圈。
6. 一个 50 ms 的 DispatcherTimer 只刷新头像数字/圆弧；原有 250 ms 的牌局 Pulse 继续负责状态推进，避免为了动画增加规则请求频率。
7. 暂停时以 pauseAt 为时间样本冻结圆弧，并显示暂停符号；恢复仍使用规则子进程已经平移的截止时间。
8. +20s 按钮调用原 extend 命令，成功后重新读取状态；actionExtensions 限制为一次，按钮随状态禁用。
9. 不在本地动画中执行弃牌或过牌：真正超时仍由原 timeout 命令决定。
10. 默认头像文字不再与中央倒计时重叠。用户自选头像仍可正常显示。

主窗口关闭时停止两个 DispatcherTimer。外部 AI 请求尚未返回且没有 botTiming 时，当前覆盖层可能保持等待态，这是现有外部策略请求时序的边界。

## 金额与交互

翻牌前快捷键显示 2x / 3x / 4x / 全下，倍数以当前最高下注为基准。翻牌后使用 33% / 50% / 100% / 全下。所有快捷值通过 SetBet 进入合法最小/最大金额范围，滑杆、输入框和按钮金额统一更新。

“全下”快捷项先选择最大金额，点击主操作按钮才执行。允许全下但不能完整加注时，主按钮保留全下入口。最终 action/amount 仍由原规则引擎校验。

金额不能由底池文本反解析，也不能为了外观将 $1/$2 真实盲注改成参考图固定的 0.20/0.50。超范围输入被夹在当前可用筹码内，NaN/Infinity 等非法输入不发送。

## 本次排障经验

- 参考截图虽然扩展名为 PNG，图像工具解码报 deflate 格式错误。先通过 Pillow 重新编码为标准 PNG，再提交内置 imagegen。
- 第一轮背景使用旧图作为额外参考，导致房间细节偏向旧图。最终仅以目标截图作为编辑目标，要求擦除 HUD 和替换品牌文字。
- 分片拉伸虽可单独调整 Logo 与牌桌，容易出现细微纹理接缝。最终背景已经接近目标比例，改为整幅原生 ImageBrush 绘制。
- QA 导出新背景前，初始 Render 可能已缓存旧场景。ExportScenes 完成后清空 bitmapCache，避免截图仍引用旧图。
- 按钮改成不同字号的 Run 后，断言应读取实际金额 Run，而不是依赖 TextBlock.Text 的平面字符串表现。
- QA 结果文件放在规则关闭、音频清理完成之后写入，并同时检查 failure.txt。
