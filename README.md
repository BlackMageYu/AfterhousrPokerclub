# AfterHours Poker Club

**v1.0 · Windows 原生私人德州扑克俱乐部**

AfterHours 是一款本地运行的无限注德州扑克练习游戏。客户端使用 C# / WPF 绘制，牌局规则与机器人策略在隐藏的本地规则进程中执行；全程不启动 HTTP 服务，也不会上传牌局或账户数据。

## 功能

- 2 / 3 / 5 / 7 人无限注现金桌，五档盲注、50–500 BB 带入、Straddle 与 15–120 分钟房间时长。
- 52 张真实扑克牌素材、发手牌 / 公共牌翻转、弃牌入池、筹码派奖等桌面动画。
- 快速弃牌：翻牌前按 `F` 即刻退出当前手，剩余机器人快速结算。
- 玩家行动时钟、房间剩余时间、机器人统一 10 秒的隐私倒计时与一次 +20 秒时间银行。
- 实时筹码管理：补码目标和退码金额均用滑杆调整，实时显示美元与 BB。
- 摊牌时显示牌型；悬停玩家头像可高亮其构成最佳牌型的五张牌。
- 牌局复盘、人物档案、VPIP / PFR 记录、身份竞猜、音乐与音效设置。
- 统一的深绿、金色 AfterHours 游戏内弹窗；所有游戏运行内确认与提示均不使用系统消息框。

## 运行

在 Windows 上双击同目录的 `AfterHours.exe`。

运行时会在本机创建 `.poker-data/` 保存账户、设置和未完成牌局；下桌后会在 `日志/` 生成牌谱。两类本地数据均已被 Git 忽略，不会提交到仓库。

## 从源码构建

要求：Windows 与 .NET Framework 4.x 自带 C# 编译器。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File native\build.ps1
```

构建会生成 `AfterHours.exe`，并嵌入 `native/AfterHours.ico` 的应用图标。

## 测试与桌面验收

```powershell
node --test tests\*.test.js
.\AfterHours.exe --qa
```

`--qa` 使用独立的 `qa/data` 存档，不会改动正常游戏数据；验收截图和结果写入 `qa/`。

## 目录说明

| 目录 / 文件 | 用途 |
| --- | --- |
| `native/` | WPF 客户端、构建脚本、本地图标与规则桥接层 |
| `src/` | 德州扑克引擎、机器人策略、人物与存档逻辑 |
| `assets/` | 场景、头像、音效和 UI 素材 |
| `素材/` | 首页参考图与完整 52 张扑克牌素材 |
| `runtime/rules.exe` | 随项目提供的本地规则运行时 |
| `tests/` | 规则、资金结算、AI 与本地通信测试 |

## 键盘操作

- `F`：翻牌前快速弃牌
- `F11`：切换全屏
- `Esc`：关闭当前游戏内面板

## 隐私

外部 AI 功能为可选项。若配置 API Key，它会通过当前 Windows 账户的 DPAPI 加密保存在本地；密钥、音乐、存档、日志、备份和 QA 产物均不会提交到本仓库。
