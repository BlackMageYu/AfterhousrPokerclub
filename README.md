# AfterHours Poker Club

**v1.1 · Windows 原生私人德州扑克俱乐部**

AfterHours 是一款本地运行的无限注德州扑克练习游戏。客户端使用 C# / WPF 绘制，牌局规则与机器人策略在隐藏的本地规则进程中执行；默认本地模式不启动 HTTP 服务，也不会上传牌局或账户数据。启用可选外部 AI 时，仅发送该机器人可见的最小决策信息，不发送账户、其他玩家私牌、牌堆或本地牌谱文件。

## 功能

- 2 / 3 / 5 / 7 人无限注现金桌，五档盲注、50–500 BB 带入、Straddle 与 15–120 分钟房间时长。
- 52 张圆角透明牌面素材；发手牌、公共牌正面平滑入桌、弃牌入池、筹码出现与派奖等桌面动画。
- 牌局按桌面视角顺时针轮转；每位玩家头像旁显示中英位置标签，例如 `[CO]关煞位`。
- 快速弃牌：翻牌前按 `F` 即刻退出当前手，剩余机器人快速结算；外部 AI 思考中也可立即响应快速弃牌或结束本场。
- 牌桌左上角提供透明双 A 精简复盘图标；可在对局中浏览本局已完成的任意一手牌，一页一手，打开期间自动暂停计时并保留未公开底牌的牌背。
- 玩家行动时钟、房间剩余时间、机器人统一 20 秒倒计时与一次 +20 秒时间银行。
- 轮到玩家行动时有单次提示音；行动计时进入后半程后，每秒播放一次轻量秒针提示音（均受“游戏音效”开关控制）。
- 实时筹码管理：补码目标和退码金额均用滑杆调整，实时显示美元与 BB。
- 摊牌时显示牌型；悬停玩家头像可高亮其构成最佳牌型的五张牌，赢家头像与手牌放大 30%。
- 155 名牌手组成统一俱乐部牌手池；无论使用本地或外部 AI 决策引擎，都会从同一批角色入桌。角色牌风只影响合理边缘决策，不会驱动频繁的盲目跟注或孤注一掷。
- 牌局复盘、人物档案、VPIP / PFR 记录、身份竞猜、音乐与音效设置。
- 统一的深绿、金色 AfterHours 游戏内弹窗；所有游戏运行内确认与提示均不使用系统消息框。

## 运行

在 Windows 上双击同目录的 `AfterHours.exe`。

运行时会在本机创建 `.poker-data/` 保存账户、设置和未完成牌局；下桌后会在 `日志/` 生成牌谱。两类本地数据均已被 Git 忽略，不会提交到仓库。

## v1.1 更新

- 新一手牌开始时的快速弃牌不再被旧的后台轮询事件拒绝：快速弃牌会安全地绑定当前翻牌前手牌，无需再次点击；普通操作仍保留严格的牌局版本校验。
- 摊牌、赢家头像和五张成牌展示固定保留 10 秒；从精简复盘返回结算桌面后也沿用同一等待时间，避免过早开始下一手。
- 改为默认以带标题栏的普通窗口启动。拖拽窗口边缘时锁定 16:9 比例，确保牌桌、按钮与头像不被拉伸变形。
- 牌桌左下角的 `HANDS` 标记改为“第 x 手牌”，实时显示当前进行手数。
- 机器人常规行动统一至少展示 1 秒：本地策略、外部 AI 成功返回与外部超时后的本地托管均适用；玩家自己的按钮不增加额外等待。
- 本地机器人依据公开行动、位置、VPIP/PFR、筹码深度、底池赔率、牌面与已公开形象构建对手范围并估算权益；复杂转牌／河牌将提高抽样量。外接 AI 会得到同一份公开范围摘要，但不会收到对手底牌或未来牌。
- 外接 AI 对明显弃牌、常规翻前入池和可过牌等简单局面优先使用本地规则；复杂大底池、多人池、高压跟注、筹码承诺和全下局面才升级为外部模型。高推理回复缺少最终 JSON 时只会重试一次短 JSON 请求，并保留脱敏诊断供日志排查。
- 100 BB 以上底池会作为重要牌局保留公开形象记录；摊牌时全下牌手亮牌，并在全下跑牌阶段显示胜率。

## v1.0.3 更新

- 公共牌取消翻牌动画：牌面从发牌位置正面朝上，平滑移动到桌面中央；翻牌、转牌和河牌均遵循同一表现。
- 下注筹码不再从玩家头像飞向桌面，而是在对应下注位按 1 → 3 层直接出现，保留下注数量递增的反馈。
- 全部 52 张牌面移除圆角外部的白色底，旋转时不再出现白色矩形边缘；WPF 牌面缩放改为高质量插值以减轻锯齿。牌背保持原样。
- 修复“本场已结束”结算原因乱码：原生端与规则进程的请求改为显式 UTF-8 传输，并由桌面 QA 验证中文文案往返。

## v1.0.2 更新

- 牌桌行动顺序调整为顺时针；每位牌手头像现在显示 `[位置缩写]中文位置名`，例如 `[CO]关煞位`。
- 修复新一手牌开始时快速弃牌可能提示“牌局已更新”以及机器人倒计时归零后不行动的问题。外部 AI 请求现在具有强制超时与本地回退保护，即使 API 忽略取消请求，牌桌也不会卡死。
- 常规外部 AI 行动窗口统一为 20 秒；仅在“面对全下且需要跟注”时放宽为 40 秒。超时、断线、非法回复时由本地策略接管，并在牌手头像旁显示“本地托管”。
- 进一步提升机器人决策的理性：以长期期望收益为目标，在低压力局面少量混合打法，避免频繁的无根据大额跟注、反加或全下。
- 牌桌左上角新增透明“双 A”精简复盘图标，可在对局中逐手翻页查看本局已完成的任意牌局；打开时自动暂停计时，未公开的弃牌仍以牌背隐藏。
- 新增行动音效：轮到玩家行动时播放提示音，行动计时进入后半程后每秒播放一次轻量秒针提示音，均受“游戏音效”开关控制。

## v1.0.1 更新

- 外部 AI 返回决策后立即行动；外部请求尚未返回时，快速弃牌与结束本场会先取消该请求并立即执行。
- 收紧本地机器人和外部 AI 的风险控制：面对 3-bet / 4-bet、大额下注和全下时，会优先依据牌力、底池赔率、筹码深度与位置做长期 EV 决策。
- 修复摊牌头像悬停的五张成牌高亮；赢家在结算阶段获得 130% 的头像与手牌展示。
- 公共牌改为先以背面移动到牌面位置，再沿纵轴翻至正面。
- 可过牌、常规翻前入池与明显弃牌优先走本地规则；其余普通翻前 / 翻牌 / 小中底池请求使用 `none` 推理。转牌、河牌、30 BB 以上底池、多人池或面对至少 75% 底池下注使用 `low`；面对全下、筹码承诺或复杂边池使用 `medium`。

## 从源码构建

要求：Windows 与 .NET Framework 4.x 自带 C# 编译器。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File native\build.ps1
```

构建会生成 `AfterHours.exe`，并嵌入 `native/AfterHours.ico` 的应用图标。

## 测试与桌面验收

```powershell
node --test tests\*.test.js
.\AfterHours.exe --qa
```

`--qa` 使用独立的 `qa/data` 存档，不会改动正常游戏数据；验收截图和结果写入 `qa/`。

## 目录说明

| 目录 / 文件 | 用途 |
| --- | --- |
| `native/` | WPF 客户端、构建脚本、本地图标与规则桥接层 |
| `src/` | 德州扑克引擎、机器人策略、人物与存档逻辑 |
| `assets/` | 场景、头像、音效和 UI 素材 |
| `素材/` | 首页参考图与完整 52 张扑克牌素材 |
| `runtime/rules.exe` | 随项目提供的本地规则运行时 |
| `tests/` | 规则、资金结算、AI 与本地通信测试 |

## 键盘操作

- `F`：翻牌前快速弃牌
- `F11`：切换全屏
- `Esc`：关闭当前游戏内面板

## 隐私

外部 AI 功能为可选项。若配置 API Key，它会通过当前 Windows 账户的 DPAPI 加密保存在本地；密钥、音乐、存档、日志、备份和 QA 产物均不会提交到本仓库。
